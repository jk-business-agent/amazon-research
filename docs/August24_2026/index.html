Methodology & Sources

Research approach: This report was produced using WebSearch and WebFetch only (no paid API). The intended source list — Amazon Movers & Shakers, Amazon Best Sellers ZGBS pages, and Amazon New Releases — was entirely inaccessible via WebFetch today; amazon.com is blocked by the network egress proxy. As a result, all product data is sourced from secondary press coverage, PR releases, retail-trade publications, and industry analysis sites discovered via WebSearch queries across ~14 distinct domains. This is a degraded-access run; treat specific rank claims accordingly.

Verification standard: VERIFIED = corroborated by at least 2 independent sources. LOW-CONFIDENCE = only one source found, or the second source is a general category reference rather than a specific product citation. Three products are marked LOW-CONFIDENCE today. No rank number, revenue figure, or percentage metric was included unless it was directly stated in a cited source's fetched content or search snippet — not inferred from context.

Fallback judgment calls: (1) Amazon.com direct access was blocked — all product discovery is secondary-source only. (2) Several domains returned in search results were also individually blocked (today.com, forbes.com, prnewswire.com, metricscart.com, accio.com, wiseppc.com, altpik.com, etc.); data from these sources is sourced only from the text snippets that appeared in search result summaries, which may represent partial content. (3) Where search result summaries synthesized across multiple sources without identifying specific articles, the synthesis itself was treated as one source (not two), requiring a second independently-fetched result for VERIFIED classification. These judgment calls are noted here rather than silently omitted.
